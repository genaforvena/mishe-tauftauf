# Inference Continuity — Brief

## Human thesis

Test whether shared world/evidence/obligations can retain or improve autonomy while inference sessions become transient.

## Accepted review

Hypotheses are not conclusions. The programme proceeds through bounded experiments with measured evidence.

## Goal

Replace the external agent loop with an internal Mishe mechanism: tight
integration of the model/tool loop into Mishe (provider-only adapter, no
external agent loop), earned through evidence-led process independence.
Minds migrate gradually, one bounded work class at a time, with the existing
harness route retained as fallback until parity is evidenced for that class.

An internal loop owns decisions the external harness currently hides:
per-call capability/tool selection, result checking against the obligation
before continuing, budget and continuation judgments, and a defined seam for
System 1 semantic advice that never replaces an available deterministic
check. Each capability is adopted only with measured evidence and
independent reading. Role/identity removal is a separate test.

## Approach

1. **Stage 0** — map real wake causes, context sources, persistent state, effects, stopping causes and successor requirements.
2. **Stage 1** — choose and execute the smallest controlled event-class experiment.
3. **Stage 2** — test named identity and perspective separately.

## Candidate experiment

CI result for an already published commit. Initially baseline and transient paths use identical recorded inputs with only one able to act.

## Constraints

- Preserve fallback, obligations and uncertainty.
- Test interruption before effect, after effect before receipt, and during external waits.
- No blind retry or exactly-once claim.
- Do not recreate a task scheduler, agent registry, memory database or universal context engine without an observed need.

## Authority

Bounded owned local prototypes, synthetic/disposable fixtures, real event observation, and evidence-led local source integration using existing delivery discipline. No global removal, unrelated process killing, remote/device/account changes, purchases or credentials.
