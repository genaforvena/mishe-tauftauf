## What this plant already does

The plant already runs an effect boundary, but without Koka's typed handler discipline. `EffectBoundary` is a single closure bound to one original store; its `dispatch` is passed as a plain callable to `drive_native` and to the caller's `execute` recheck, with no effect row in the signature. The durable journals record intents/starts/outcomes as bytes, not as a typed row `<emit|console>` that the type checker could discharge. There is lexical `with` in Python but no `with handler` scoping that dynamically rebinds which `emit`/`yield` handles the operation; nesting is hard-wired (ledger -> boundary -> loop), not a stack of handlers that an inner action could mask to bypass. Resume discipline is also implicit: callers either produce a value that the boundary journals as `completed` or raise, which becomes `unknown` — there is no `ctl` vs `fun` distinction and no explicit `resume` handle whose arity (zero/once/many) is checked.

## What is new here

The transferable mechanism is Koka's typed handler + masking (Leijen §3.4–§3.4.7) with explicit resume arity. Declaration `effect fun emit(msg: string):()` makes the operation abstract; its implementation is supplied only at a `with handler{ fun emit(msg){ ... } }` or `with ctl yield(i){ resume(...) }` site, which discharges that effect from the enclosed action's row and composes rows `<console,emit>`. `mask<eff>(action)` is the isolation primitive: it hides inner handling once — "mask only masks an operation once for its innermost handler" — so an effect raised inside the masked action skips the nearest handler and is handled by the next outer one, exactly like masking a Unix signal. This lets a higher-order wrapper (Koka's `mask-print` example: `val x = mask<raise>(action)` around `with handler{ ctl raise(msg) ... }`) hide its internal `raise` handling from callers that also handle `raise`. The compiler further distinguishes `fun` (tail-resumptive, resumes exactly once with final result, compiled as a direct call via evidence passing) from `ctl` (general, may resume zero/many times, must yield upward). The plant has the "effect happens, handler decides whether to resume and with what" shape, but without rows, without mask, and without declared resume arity.

No compilation or durability claim is imported. Koka's Perceus/FBIP/evidenced-passing C compilation is not claimed for Python. The gap is a naming/type discipline for the existing boundary, not a runtime change.
