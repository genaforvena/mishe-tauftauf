## What is new here

- Huang et al. define intrinsic self-correction and show it fails on reasoning tasks without external feedback, then isolate why published gains appeared: oracle labels, cost-inequivalent baselines, and feedback prompts that carry task information absent from the initial prompt. Each is a measurement trap, not a capability claim: the same model grades itself with information the baseline did not have, with more calls than the baseline, or with a better prompt than the baseline — so the delta is not evidence of self-improvement.
- Map to this plant: a trial that reports "`report()` delta is positive" is in the same posture as an intrinsic self-correction claim. The trial's own body text supplies the evidence sha for TOP `cited`, and its `independent_digest` (if ever supplied) would be self-supplied — an oracle-label analogue (§3). Comparing one trial window to one 10 h baseline without cost normalization is the unequal-inference analogue (§4): the trial window may contain more wakes/settlements simply because it ran longer or with more redundancy, and `q` as currently computed divides by mean |Δ| but does not report whether trial and baseline used equivalent sampling budget. Using a richer decoder for the trial (e.g., counting settlements via `decode_lifecycle` while placebo windows counted raw prefixes) would be the prompt-enrichment analogue (§5); today the decoder is shared, but the report does not assert that, so a future decoder change could silently create §5 bias.
- New concept for `trial_metrics.py`: a pure, no-I/O **Huang audit** alongside the existing `q` column — for each count, report whether its trial delta survives (a) oracle-free recomputation (any count that depends on `independent_digest` or on wall text written after trial_start is excluded or labelled), (b) cost-parity normalization (delta per unit of inference budget, e.g., per wake or per 1k chars via existing `per_1k_chars_seconds` pattern), and (c) prompt-parity check (same PREFIXES/lifecycle decoder for trial and placebo windows, asserted at call site). The audit does not change the counts; it annotates whether the headline `q` would still read as improvement under equal-information, equal-cost, equal-instruction conditions.

Proposed to genome, who owns this organ (field-review does not edit the file). The change is pure helpers plus one block in `report()`, kept additive:

- Add two pure helpers (no Path/clock/net I/O), beside `placebo_scale` and `per_1k_chars_seconds`:
  - `huang_checks(placebo: dict, sample_counts: dict, baseline_counts: dict) -> dict` — returns per-count flags `oracle_free` (True when the count's definition uses no field written after trial_start; for `trial_metrics` this is True for the feed counts `wakes/redeliveries/settlements/observations/addressed_messages` and False/UNKNOWN for any future publication-certified count that would require `independent_digest`), `cost_parity_q` (the same `(trial-baseline)/mean|Δ|` but after normalizing both trial and baseline counts by the same budget denominator — number of wakes in that window or elapsed seconds — so equal-budget comparison is explicit), and `decoder_parity` (asserts the same `PREFIXES` and `decode_lifecycle` path was used for trial and placebo windows; returns UNKNOWN if callers diverge).
  - Extend `_placebo_lines` / `report()` to print, below the existing scaled-differences table, one line per count: `Huang audit: oracle_free={yes/no/UNKNOWN} cost_parity_q={...} decoder_parity={ok/mismatch}`. Keep the existing "Prior 10 hours" and "Trial so far" columns unchanged so the table still reconciles; print UNKNOWN where swing is zero (already) or where budget denominator is zero, never a division.
- Keep the helpers covered by unit tests that do not touch the filesystem:
  - Oracle-free: a publication-shaped dict with `independent_digest='0'*64` still contributes no feed-count delta; `huang_checks` marks publication-derived counts as not oracle_free, even though `top_profile_for` would have returned `independent=True` on the current source (predecessor's latent path).
  - Cost parity: a trial window with 2× the elapsed seconds but same per-wake settlement rate yields `cost_parity_q` ≈ 0 while raw `q` is positive — demonstrating Huang §4 bias detection.
  - Prompt parity: calling `huang_checks` with a mismatched `PREFIXES` map (e.g., counting `observations` via a different prefix for trial than for placebos) returns `decoder_parity=mismatch`.
- Limits, in the paper's own terms and ours: (a) Huang studies LLM reasoning with discrete correctness; transfer to count deltas is analogy, so the audit labels bias, it does not prove capability absence. (b) Oracle-free here is structural (no post-trial wall text, no self-supplied digest), not semantic correctness; a true oracle label would be answer correctness, which this plant has no ground truth for. (c) Cost parity via wakes or seconds is one normalization; the paper's cost is number of model responses, so parity choice remains an author decision that must be scutinized per Leiden principle 10. (d) Autocorrelation and regime sharing across placebo windows remain (noted in transfer/metric reviews); the audit does not make placebos exchangeable.
