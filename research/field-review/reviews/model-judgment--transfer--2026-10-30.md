# Prediction is a set, not a point — conformal turns any judge's heuristic into a rigorous coverage guarantee

## What we read

**Anastasios N. Angelopoulos and Stephen Bates — "A Gentle Introduction to Conformal Prediction and Distribution-Free Uncertainty Quantification", arXiv:2107.07511v6 [cs.LG] 7 Dec 2022** — read full primary source at:

- <https://arxiv.org/abs/2107.07511> (arXiv abstract, v6 7 Dec 2022)
- <https://arxiv.org/pdf/2107.07511.pdf> (PDF 5_360_733 bytes fetched 200 2026-10-30 at /tmp/conformal21.pdf, 51 pp., sha256 c69aa191d8363c25b36685db4adb7e6980e55ee39892fd3626206c16e1e0efa1, Creator pdfTeX-1.40.21, 51 pages, LaTeX with hyperref)

The paper is the field's canonical hands-on bridge from Vovk, Gammerman and Saunders to modern split conformal practice, with code notebooks and ImageNet / quantile-regression worked examples. Four passages carry the mechanism this plant can borrow without lifting its theorems — pagination is v6 page numbers, quotations via `pdftotext`:

1. **Split conformal in four lines — definition, quantile, and the guarantee (§1 pp.3–5, Fig.2 p.4, Theorem 1 p.5).** Formal setup: reserve `n≈500` fresh i.i.d. calibration pairs `(Xi,Yi)` unseen in training. Score `si = 1 − f̂(Xi)Yi` (one minus true-class softmax; high when badly wrong). Define `q̂` as the `⌈(n+1)(1−α)⌉/n` empirical quantile of `s1…sn` (ceiling correction). Test-time set `C(Xtest) = { y : f̂(Xtest) y ≥ 1−q̂ }` i.e. `{y: s(Xtest,y) ≤ q̂}` (2). Guarantee (1): `1−α ≤ P(Ytest ∈ C(Xtest)) ≤ 1−α + 1/(n+1)` for any model and any unknown distribution. Abstract framing: "a user-friendly paradigm for creating statistically rigorous uncertainty sets/intervals ... valid in a distribution-free sense: they possess explicit, non-asymptotic guarantees even without distributional assumptions or model assumptions. One can use conformal prediction with any pre-trained model." Instructions §1.1 p.5 generalize to any `s(x,y)∈ℝ` with larger = worse agreement, forming `C(Xtest)={y:s≤q̂}`. This is the object to transfer — not a model, a wrapper around any heuristic.

2. **The guarantee is free; the usefulness is the score (§1 p.5 "Choice of score function").** "How is it possible to construct a statistically valid prediction set even if the heuristic notion of uncertainty ... is arbitrarily bad?" Answer: if scores rank error well, sets are small for easy inputs and large for hard; if scores are random noise, "the sets will contain a random sample of the label space, where that random sample is large enough to provide valid marginal coverage." Quoted conclusion: "although the guarantee always holds, the usefulness of the prediction sets is primarily determined by the score function. ... Therefore, constructing the right score function is an important engineering choice." This is the transfer's caution: coverage without efficiency is honest but useless.

3. **Classification with Adaptive Prediction Sets — cumulative-softmax score (§2.1 pp.6–7, Fig.3–4).** Motivation: plain `1−p_true` gives smallest average set size but "tends to undercover hard subgroups and overcover easy ones." Oracle would greedily include top classes until mass `>1−α`. Conformal APS score: `s(x,y)= Σ_{j=1}^{k} f̂(x)_{πj(x)}` where `y=πk(x)` under confidence-sorted permutation `π` — the cumulative mass needed to reach the true label. Quantile `q̂` as before, set `C(x)={π1…πk}` where `k = sup{ k0: Σ_{j=1}^{k0} f̂_{πj} < q̂ }+1` (3, Fig.3 Python). Uses all classes, not just predicted one. Code in Fig.3 shows `cal_srt = cumsum(sorted smx)` and `cal_scores = take_along(cumsum[true_label])`. Fig.4 visualizes cumulative bars. With tie-breaking, satisfies (1); without, still satisfies lower bound. The authors note practical improvements are implemented in the cited repos.

4. **Conformalized quantile regression + the extensions catalogue (§2.2 pp.8–9 Fig.5–6, §4 pp.16–26, Appx A).** For continuous `Y`, fit quantiles `t̂_{α/2}, t̂_{1−α/2}` then score `s(x,y)=max{ t̂_{α/2}(x)−y, y−t̂_{1−α/2}(x) }` and interval `C(x)=[t̂_{α/2}−q̂, t̂_{1−α/2}+q̂]` (4, Fig.5 code). Same quantile, continuous set. §4 then shows the recipe generalizes without changing the core: group-balanced (4.1), class-conditional (4.2) `P(Y∈C(X) | Y=k)≥1−α` per class, risk control / Learn-then-Test (4.3 / Appx A), outlier detection (4.4), covariate shift with weighted quantiles (4.5), drift (4.6), multilabel, segmentation, time-series, selective classification (5.1–5.5). Limits stated p.11–15 (§3): adaptivity evaluated, calibration set size effect, marginal `≥1−α` is not conditional `P(Y∈C(X)|X=x)≥1−α`; guaranteeing that is impossible without assumptions.

**Limits the source states and this review keeps.** Requires exchangeable (i.i.d.) calibration and test pairs, `n` moderate (500 is typical) and disjoint from training; guarantee is marginal, not per-input or per-class unless group/class-conditional variant is used; score choice controls set size, not validity; tie-breaking nuance for discrete `Y` (footnote p.4); history extends to full conformal, CV+/jackknife+ (§6) not needed for split variant.

**Why this source, for this cell.** `model-judgment--transfer` asks for a cross-domain transfer of model judgment onto a plant part. Conformal is a *statistics-to-ML* transplant: a distribution-free wrapper born in conformal inference (Vovk 2005) that makes any black-box classifier's heuristic into a set with a finite-sample guarantee. The plant's `model-judgment` field currently calibrates a point probability (`completions_judge`, `jev_judge`, Guo ECE, Wang invert, Nixon critique) — all still point predictions. Conformal's transfer is orthogonal: keep the point verdict if you want, but publish the set that achieves `90%` coverage by construction, on held-out data, with one quantile.

## What is new here

**Wrap the judge's heuristic in a split-conformal calibration step that turns it into a prediction set with an explicit, non-asymptotic marginal coverage guarantee — no retraining, no logit access, one quantile, always honest, whose size is the operational signal.**

1. **From heuristic to rigorous per input without touching the model — split recipe (Gentle Intro §1.1 steps 1–4, Fig.2, Thm.1).** Take any score `s(x,y)` the plant can already compute — e.g. `1−p_true` from verbalized `{"yes":p1,"no":p2,"unknown":p3}` or cumulative APS mass — hold out `n` fresh `(evidence, expected∈{yes,no,unknown})` calibration pairs disjoint from the smoke suite, compute `si`, set `q̂ = quantile(si, ceil((n+1)(1−α))/n; method=higher)`, and at test time emit `C(x)={y:s(x,y)≤q̂}`. Theorem 1 gives `P(Ytest∈C)≥1−α` marginally over calibration+test randomness, for any `s`, any unknown distribution, any pre-trained `f̂`. The one-line Python is exactly Fig.2 right panel: `qhat = np.quantile(scores, ceil((n+1)*(1-alpha))/n, method='higher')`. For discrete `K∈{2,3}` this is a set over `{yes,no}` (or with `unknown`), for a thresholded scalar it is an interval; §2.2 interval form `C=[t̂_{α/2}−q̂, t̂_{1−α/2}+q̂]` transfers to any scalar uncertainty (e.g. latency/age).

2. **Usefulness lives in the score — choose APS cumulative over plain `1−p` when you want adaptivity (Gentle Intro p.5 choice discussion + §2.1).** The guarantee holds for random `s`, but sets are "useless" — a random score samples labels at random at the size needed for `90%` marginal coverage. A well-ranked score gives small sets on easy inputs and large on hard. The paper proves `1−p_true` minimizes average size yet undercovers hard subgroups; APS `s(x,y)=cum_sm(include until truth)` adapts per subgroup. Practical consequence: for the plant's `{yes,no}` with `unknown` as abstain, plain `1−p` yields many `{yes}` sets that are marginal-correct but subgroup-blind; APS yields `{yes,no}` exactly when `p` mass is split, which is the contested-evidence signal the plant already asks about in its atomic questions.

3. **Same quantile, many extensions — class-conditional, group-balanced, selective (§4.1–4.5 / §5.5, Appx A).** Keeping `q̂` per class gives `P(Y∈C|Y=k)≥1−α` (4.2) — needed because `P(yes)` miscalibration is not symmetric; per-group `q̂_g` (4.1) when evidence carries a domain tag; selective classification (5.5) `C=∅` is the abstain signal already named `unknown`, now with a level. Covariate-shift weighting (4.5) matters if calibration and deployment evidence differ in source mix. All are one quantile per slice; none change `SYSTEM_PROMPT` or `Config`.

4. **Marginal, not conditional — honesty about what is not promised (Gentle Intro §3.1/§3.3).** The guarantee is averaged over calibration and test randomness; `P(Y∈C(X) | X=x)≥1−α` for every `x` is not claimed and is impossible distribution-free. Empirical adaptivity (§3.1) and calibration-size (§3.2) plots show coverage vs set size tradeoff. For this plant: report `alpha`, `n`, and empirical coverage on a second held-out slice alongside `q̂`; do not claim per-evidence conditional coverage. This aligns with the plant's existing `unknown` honesty and with Nixon's critique that a single number without axes is unreproducible.

**Limits the review keeps from the source.** Exchangeability required — calibration and test pairs must be i.i.d. draws from the same distribution, and `n` must be large enough that `ceil((n+1)(1−α))/n` is not degenerate (`n<1/α` gives `q̂=max si`, still valid but vacuous). No claim imported about a tuned `α` or `q̂` value — those are always fit to the plant's own held-out pairs. Adaptive score's `p.37 vs 0.59` rank stability (Nixon) is not reclaimed here; conformal adaptivity is about subgroup coverage, not ECE ranking.
