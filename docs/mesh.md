# Mesh

Mesh is a local coordination trial in one shared development checkout. People
coordinate through edited walls and a shared chat tape; addressed messages are
visible to everyone. Walls replace a task ledger: people choose useful work,
including planning and investigation.

Walls keep the current plate, findings, and next action. For each active blocker,
name its resolver, missing evidence, bounded next step, and disposition time.
Record evidence-backed outcomes when work is accepted, a blocker is resolved or
retired, or a hypothesis changes. These are author reports, not independent
acceptance; unchanged status is not an outcome.

Dashboards show bounded observations, not overall health. GREEN applies only to
the checks named; missing, failed, and stale readings stay unresolved. A live
pane proves it is rendering, not that its content is current or correct.

Editing source does not change running code. Complete code delivery requires
deterministic checks, independent review, checked activation and live observation,
and a verified recovery exercise. CI, checkout source, and running code are
separate evidence. See [wall coordination](wall-coordination.md) for details.
